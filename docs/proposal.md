| `/` | **메인 대시보드** | Next.js ISR (On-Demand 갱신) | 실시간 글로벌 체온계, 국내외 TOP 3 키워드, 주요 6개 권역 이슈 보드 |

### 2.2 메인 대시보드 화면 구성 (3-Step Scan UX)

#### ① 최상단: 글로벌 시장 체온계 & 원클릭 공유 바

* **시장 핵심 지표 티커:** 원/달러 환율, 코스피, 나스닥, 미 국채 10년물 금리, 국제유가(WTI)의 현재가 및 전일 대비 등락률을 1줄 고정 바(Sticky Bar)로 노출합니다.
* **원클릭 브리핑 복사 (`[📋 오늘의 30초 브리핑 복사]`):** 클릭 시 국내·세계 핵심 키워드 6줄 요약과 서비스 URL이 깔끔한 텍스트 포맷으로 클립보드에 복사되어 카카오톡이나 사내 슬랙(Slack)에 즉시 공유할 수 있습니다.

#### ② 상단 하이라이트: 오늘의 핵심 키워드 6선 (5초 스캔)

* 화면 좌우(모바일 상하) 분할로 `[🇰🇷 국내 핵심 TOP 3]`와 `[🌍 세계 핵심 TOP 3]`를 배치해 현재 가장 파급력이 큰 단어 6개와 한 줄 요약을 즉시 노출합니다.

#### ③ 메인 그리드: 국내 vs 주요 5개 권역 이슈 보드 (30초 스캔)

* 한국 경제와 안보에 직접적 영향을 미치는 한국(KR) + 5개 권역(미국 US, 중국 CN, 일본 JP, 유럽 EU, 중동 ME)만 엄선하여 PC 기준 2열×3행 카드 그리드로 배치합니다.
* **권역별 카드 내부 구조 (권역당 상위 3개 이슈 노출):**
1. **핵심 단어 (Badge):** 예) `#미_연준_금리동결`, `#엔화_약세_심화`
2. **팩트 한 문장:** 육하원칙 기반의 건조하고 명확한 사실 전달 (40~55자 이내)
3. **내 지갑·일상 영향 (Highlight Box):** 환율, 대출금리, 물가, 국내 증시·산업에 미치는 영향을 한국인 관점에서 한 줄로 번역 제공



#### ④ 상세 인터랙션: 아코디언 확장 패널 (체류 시간 확보)

* 이슈 카드를 클릭하면 외부 언론사로 즉시 이탈하지 않고, 카드 하단이 부드럽게 펼쳐지며 **배경 맥락 3줄 요약 + 향후 관전 포인트 1줄 + 원문 기사 출처 링크**를 표시합니다.

## 3. 데이터 수집 및 AI 자동화 파이프라인

### 3.1 하이브리드 데이터 수집 전략 (트렌드 + 주요 기사 결합)

구글 트렌드 RSS는 **실시간 급상승 검색어(Search Spike)** 기준이므로 단독 사용 시 연예·스포츠 가십이 다수 포함됩니다. 이를 보완하기 위해 '검색 급등 트렌드'와 '경제·국제 주요 뉴스 RSS'를 결합해 수집합니다.

* **국내 이슈 수집:**
* Google Trends 한국 급상승 검색어 RSS: `[https://trends.google.com/trending/rss?geo=KR](https://trends.google.com/trending/rss?geo=KR)` (검색량 급등 키워드 및 연관 기사 `ht:news_item` 확보)
* Google News 한국 경제·주요 뉴스 RSS: `[https://news.google.com/rss/headlines/section/topic/BUSINESS?hl=ko&gl=KR&ceid=KR:ko](https://news.google.com/rss/headlines/section/topic/BUSINESS?hl=ko&gl=KR&ceid=KR:ko)`


* **해외 권역별 이슈 수집:**
* Google Trends 주요국 RSS: `[https://trends.google.com/trending/rss?geo=](https://trends.google.com/trending/rss?geo=){US|JP|GB|DE}`
* Google News 권역·매체 필터 RSS (`when:1d` 활용): 중국(SCMP, 한중 경제 검색 RSS), 중동(Al Jazeera, Reuters), 미국·유럽(Bloomberg, BBC World)



### 3.2 AI 정제·요약 엔진 (Gemini Flash API)

Python 배치 스크립트가 수집한 원문 헤드라인을 권역별로 묶어 LLM에 전달하며, `Structured Outputs(JSON Schema)`로 출력 규격을 강제합니다.

* **AI 필터링 및 생성 프롬프트 규칙:**
1. **노이즈 제거:** 연예, 스포츠 경기 결과, 단순 범죄·가십 키워드는 배제하고 **거시경제, 산업, 기술, 정책, 국제정세** 이슈만 선별할 것.
2. **중복 병합:** 동일 사건을 다룬 여러 매체의 헤드라인은 하나로 병합해 권역별 파급력이 큰 상위 3개 이슈만 도출할 것.
3. **생활·경제 번역:** 모든 이슈에 대해 한국 직장인·투자자 관점의 실질적 영향(`market_impact`)을 반드시 1줄로 작성할 것.
4. **환각 방지:** 제공된 RSS 헤드라인과 스니펫에 없는 수치나 사실을 추론하지 말 것.

## 4. 시스템 아키텍처 및 데이터베이스 설계 (Vercel + Supabase)

### 4.1 전체 데이터 흐름도

```
[GitHub Actions (Cron: 3시간 주기, 일 8회)]
       │
       ▼
[Python 수집·AI 스크립트] ──▶ Google Trends / News RSS + Gemini Flash API 호출
       │
       ▼
[Supabase PostgreSQL] ────▶ briefings / issues 테이블 UPSERT + health_check 기록
       │
       ▼
[Next.js Revalidate Webhook] ─▶ /api/revalidate 호출로 Vercel ISR 캐시 즉시 갱신
       │
       ▼
[Vercel Edge CDN] ─────────▶ 사용자에게 정적 수준의 초고속 응답 제공 (DB 부하 최소화)

```

### 4.2 무료 플랜 한계 극복을 위한 핵심 기술 설계

초기 비용 **$0**로 안정적인 무유지보수 운영을 달성하기 위해 플랫폼별 제약을 아래와 같이 우회합니다.

| 플랫폼 / 역할 | 무료 티어 제약 사항 | 해결 아키텍처 (우회 설계) |
| --- | --- | --- |
| **Vercel (Hobby)**<br>

<br>프론트엔드 호스팅 | • 자체 Cron Job은 **1일 1회**로 제한됨<br>

<br>• 월 대역폭(Fast Data Transfer) **100GB**, Edge Requests **100만 건** 한도<br>

<br>• 원칙적으로 **상업적 광고(AdSense) 운영 제한** | • 스케줄링은 **GitHub Actions**에서 수행<br>

<br>• Next.js ISR (`revalidate = 1800` + On-Demand Revalidation)을 적용해 접속마다 DB를 조회하지 않고 CDN 캐시 서빙<br>

<br>• 초기에는 광고 없이 운영하며 트래픽 검증 후 유료 전환 또는 이전 |
| **Supabase (Free)**<br>

<br>데이터베이스 | • DB 용량 **500MB**, 월 Egress **5GB**<br>

<br>• **7일간 DB 활동이 없으면 프로젝트 자동 일시정지(Pause)** | • 텍스트 위주 데이터이므로 500MB로 수년 치 아카이브 저장 가능<br>

<br>• 3시간마다 배치가 DB에 데이터를 기록하며, 수집 실패 시에도 `health_check` 테이블을 갱신해 일시정지 원천 방지 |
| **GitHub Actions**<br>

<br>배치 스케줄러 | • Public 저장소 무료, Private 저장소 월 2,000분 무료 | • 일 8회 실행(1회당 약 40초 소요) 시 월 160분 수준으로 무료 한도 내 여유롭게 운영 |

### 4.3 Supabase 데이터베이스 스키마 (초기 3개 테이블)

1. **`briefings` (회차별 브리핑 메타 데이터)**
* `id` (UUID, PK)
* `briefing_date` (DATE, Unique — 일자별 대표 아카이브 조회용)
* `published_at` (TIMESTAMPTZ — 최신 갱신 시각)
* `domestic_top3` (JSONB — 국내 핵심 키워드 3개 및 요약)
* `global_top3` (JSONB — 세계 핵심 키워드 3개 및 요약)
* `market_indicators` (JSONB — 환율, 지수, 유가 등 시장 지표 스냅샷)


2. **`issues` (권역별 개별 이슈 카드 데이터)**
* `id` (UUID, PK)
* `briefing_id` (UUID, FK → `briefings.id`)
* `region_code` (VARCHAR — `KR`, `US`, `CN`, `JP`, `EU`, `ME`)
* `rank` (INT — 권역 내 중요도 순위 1~3)
* `keyword` (VARCHAR — 핵심 단어 태그)
* `fact_one_line` (TEXT — 팩트 한 문장 요약)
* `market_impact` (TEXT — 내 지갑·일상 영향 한 줄)
* `context_3lines` (JSONB — 상세 배경 맥락 3줄 배열)
* `source_name` (VARCHAR — 원문 언론사명)
* `source_url` (TEXT — 원문 기사 링크)
* `created_at` (TIMESTAMPTZ)


3. **`system_logs` (배치 헬스체크 및 일시정지 방지용)**
* `id` (SERIAL, PK), `executed_at` (TIMESTAMPTZ), `status` (VARCHAR), `summary` (TEXT)

## 5. 단계별 실행 로드맵 및 수익화 전환 전략

### 5.1 Phase 1: MVP 개발 및 트래픽 검증 (1~4주차, 비용 $0)

* **1주차 (백엔드/배치):** Supabase 테이블 생성 및 Python 수집·요약 스크립트 개발 (RSS 파싱 + Gemini Flash JSON 출력 검증).
* **2주차 (프론트엔드):** Next.js App Router 기반 대시보드 UI, 아코디언 상세 패널, 원클릭 복사 기능, `/archive/[date]` 페이지 구현.
* **3주차 (자동화 및 배포):** GitHub Actions Cron 연동, Vercel 배포, 구글 서치 콘솔·네이버 서치어드바이저 사이트맵 등록.
* **4주차 (지표 관찰):** 직장인 커뮤니티(블라인드, IT·재테크 오픈채팅 등) 초기 공유를 통해 **일 방문자(DAU), 원클릭 복사율, 아코디언 클릭률** 측정.

### 5.2 Phase 2: 수익화(AdSense) 및 인프라 확장 (트래픽 안착 이후)

* **전환 기준:** 일 순방문자(UV) 1,000명 이상 또는 일자별 아카이브 페이지의 자연 검색 유입이 꾸준히 증가하는 시점.
* **인프라 및 약관 대응:** 상업적 광고 게재를 위해 Vercel Pro 플랜($20/월)으로 업그레이드하거나 Cloudflare Pages로 프론트엔드 호스팅을 이전하여 약관 리스크 해소.
* **애드센스 최적화 배치:**
* **Slot A (상단 리더보드):** `오늘의 핵심 키워드 6선`과 `권역별 이슈 보드` 사이 가로형 배너 (고정 높이 지정으로 레이아웃 밀림 방지).
* **Slot B (인피드 광고):** `한국·미국` 카드 행과 `중국·일본` 카드 행 사이 자연스럽게 삽입되는 네이티브 카드 배너.
* **Slot C (상세 패널 내부):** 사용자가 `배경 맥락 3줄`을 펼쳐볼 때 하단에 노출되는 사각형 광고 (고의도 체류 구간).
* 모든 이슈의 `market_impact`에 금융·경제·산업 키워드가 포함되어 있어 일반 뉴스 대비 높은 클릭당 단가(CPC) 확보 가능.
